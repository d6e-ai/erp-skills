# Repository language policy

Date: 2026-09-03

## Decision

- Use English as the default language for repository instructions, general documentation, shared skills, Singapore skills, migration skills, and integration skills.
- Allow Japanese only in Japan-specific skill content under `skills/jp/`.
- Preserve code identifiers, SQL names, product names, and official terminology when translation would reduce precision.

[`docs/design.md`](../design.md) is the normative source for this policy.
